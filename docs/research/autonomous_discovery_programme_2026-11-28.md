## Research decisions and budget

The director uses a small, typed set of economic explanations and supported feature transformations, without arbitrary model code or parameter generation. It read the original inconclusive result and positive raw momentum rank association, then tested whether volatility-adjusted continuation explained that association. After a negative result, it evaluated persistent liquidity as a distinct source of selection information. The two weak payoff results raised the priority of measuring overnight price discovery before the first actionable entry. A sector-relative candidate was blocked on dated membership, which did not consume a trial or block the other families.

The follow-on budget was three looks total and one per family. The frozen protocol and read-only checkpoint digest were registered before each study. The director estimates the maximum nonoverlapping windows using the formation dates before registration. Actual inference re-estimates sample size and minimum detectable excess from measured dates. It uses the existing dependence estimator with a Bonferroni adjustment across these three follow-ons for the research acceptance bound. The table reports unadjusted descriptive 95% intervals. The baseline reversal is a separate, earlier discovery look. No reserved observations were used.

## Operation and verification

In scratch, retain a byte copy of the checked checkpoint (SHA-256 `d10b5bb5ce0d22a9e173bf8d2ecbfef5d42702a224fa8eb6282704c8e56d3882`) and the registry containing the completed reversal. Set `QT_RUNTIME_ROOT` and `QT_OUTCOME_DISCOVERY_CHECKPOINT` before starting an isolated scheduler. The existing closed-market resource gate enqueues only the next unspent slot. The per-runtime lock covers selection through commit. The registry records RUNNING before calculation and an immutable result on completion. Retry resumes the same spec and slot. A deterministic measurement failure records an inconclusive spent look and allows unrelated work. If the scheduler has exhausted retries or the underlying snapshot or implementation changed, its failed job remains visible in the existing scheduler and the slot stays pinned pending recovery. No new key silently spends that slot again.

The completed programme has no promising test to freeze for external validation. A future promising result would preserve its exact specification and a prospective protocol, with no automatic activation. A dated sector universe and more action-aware observations over additional independent periods are required before new relevant hypotheses can be tested. The deterministic generator is bounded to the implemented feature and target vocabulary. It does not claim general autonomous model invention.
