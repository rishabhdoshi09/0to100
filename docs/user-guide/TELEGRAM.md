# Telegram

QuantTerm can send you messages on Telegram and offer quick **paper** actions.

## The one rule that never changes
**Telegram is paper-only.** A tap in Telegram can only ever record a *pretend* trade.
It **cannot** place a real order — ever. This is built in, not a setting.

## What a Telegram tap does
- Records a **paper** (pretend-money) trade.
- Shows up as a paper position you can review.
- Never reaches a real trading account.

## What it does NOT do
- It does not place a live order.
- It does not bypass the daily safety stop or trade limit.
- It is not a reason to trust a setup blindly — read the plain "why" first.

If anyone tells you Telegram can place real orders in QuantTerm, they are mistaken.
