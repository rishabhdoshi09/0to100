# Troubleshooting

| You see… | It means… | Do this |
|---|---|---|
| "Data missing" | Required data is not installed | Open Data Health; follow the install step |
| "Data is old" | Prices are stale | Refresh data before trusting any price |
| "Daily safety stop active" | Today's loss limit was hit | Stop for today; it resets tomorrow |
| Trades used = allowed | Daily trade limit reached | Come back tomorrow |
| "No valid opportunity" | Nothing met the rules | Nothing to do — this is normal and fine |
| "Live trading locked" | Real money is off on purpose | Keep practising in Paper |
| "INCONCLUSIVE — DATA UNAVAILABLE" | Research data not installed | Install the data (Data Health) |
| A setup was "Skipped" | It failed a rule | Open it and read the plain reason |
| A setup is "Waiting" | Breakout hasn't closed above the price | Wait for the candle to close |
| "No fill" | A real order couldn't have happened there | Nothing — this keeps practice honest |
| JARVIS says unavailable | The AI helper needs a key / is resting | You can use everything else normally |

**Golden rule:** if something is unclear, open the page's "What is this page?" panel or
the Glossary. You should never be left guessing.
