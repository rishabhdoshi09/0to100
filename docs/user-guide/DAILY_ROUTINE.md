# Your daily routine (5 steps)

A good day is not necessarily a profitable day. **A good day is one where the system
followed its rules and protected the account.**

1. **Open Simple Home.** Is it "Ready", or does something need attention?
2. **Check data health.** If it does not say healthy, stop and fix that first. Never
   trust prices when data is missing or old.
3. **Confirm your mode.** It should say *Paper practice*. Real money stays locked.
4. **Read the setups.** For each, read the plain **why** — especially the *skips*.
   Check entry, stop, and the **most you could lose** before anything.
5. **Let it record everything.** Accept "no trade" when nothing qualifies.

## The daily checklist
- [ ] Data is healthy
- [ ] Correct mode selected
- [ ] Safety limits reviewed
- [ ] Autopilot state confirmed
- [ ] Open positions reviewed
- [ ] Unresolved warnings checked

If the daily **safety stop** is active, you are **done for today**. Do not try to
"make it back". It resets on the next trading day.
