# Getting around

The menu is grouped by what you want to do, not by how the software is built.

## TODAY
- **Simple Home** — the whole picture: ready? safe? what next?
- **Opportunities** — possible setups, and *why* each was taken, skipped or is waiting.
- **My Positions** — your open *paper* positions, with entry, stop and maximum loss.
- **Alerts** — things to look at (an alert is **not** a "buy now" command).

## LEARN AND VERIFY
- **Research Lab** — where the system tests ideas on history. It makes **no** trades.
- **What We Have Learned** — plain results: PASS / FAIL / INCONCLUSIVE.
- **Reports** — summaries of what happened.

## SYSTEM
- **Safety and Limits** — the daily stop, the trade limit, the live lock.
- **Data Health** — is the data present and fresh?
- **Settings** — change things carefully (each safety change asks a specific question).
- **Help** — this manual and the glossary.

Every page has a **"What is this page?"** panel answering: what is this, why it matters,
what to do, what happens next, and where to go after.

**Advanced Mode** (a toggle) shows technical detail. It only changes what you *see* —
never what the system is allowed to *do*.
